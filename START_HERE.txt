CITI BIKE FLEET AVAILABILITY PLANNER - VERSION 2.3
==================================================

This portable copy contains the app, trained forecasting models, and processed
NYC trip/weather/geography data. It DOES NOT contain raw ride-level datasets.

Total included data/code files: 45
Size before ZIP compression: 29.7 MiB

MAC SETUP (Python must already be installed)
1. Unzip this package and open Terminal in the extracted folder.
2. Run:
   python3 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   .venv/bin/python -m streamlit run app_v2_3.py
3. Open the Local URL shown by Terminal (usually http://localhost:8501).
4. Keep Terminal open while using the app. Stop with Control+C.

You do NOT need to run preprocessing or model training.
You DO need to install the Python packages on the machine running the app.

HOW TO PRESENT
For the most reliable demo, run the app locally from your Mac and keep
this extracted portable folder as a backup. Test while disconnected from
Wi-Fi: live station status and weather may be unavailable, in which case
the app labels its saved-status / historical-weather fallback. Forecast
values can differ when live station status or weather snapshots change.

SHARING VIA WEB
This is a complete app folder, not an already-hosted website. To obtain
an internet URL, deploy the files in this extracted folder to a compatible
Python/Streamlit host, e.g. Streamlit Community Cloud via GitHub.
Only share a deployed URL after testing data loading, model loading, maps,
resource usage, and fallback status.

IMPORTANT
- No actual employee dispatch is performed.
- Trip-history models estimate completed rides, not attempted/unmet rentals.
- Predictions compare current/saved inventory against a hypothetical future
  starting state; the physical station-level feasibility must be checked.
- Do not delete the original complete CitiBike_Project on your Mac.
- requirements.txt was generated using the installed library versions in
  the environment running this packager. It may need adjustment on an
  incompatible operating system or Python version.
